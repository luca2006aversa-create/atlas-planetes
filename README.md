# Kibsu · atlas du système solaire

Atlas du système solaire en 3D et étude de site « Choisir un site au pôle sud de la Lune » (lecture d'ingénieur et lecture d'architecte).

Auteur : Luca Aversa, étudiant en architecture (ENSA Normandie, Hanoi Architectural University).

- `index.html` : l'atlas (globe 3D, missions)
- `etude/` : l'étude de site du pôle sud lunaire

Données publiques : NASA/GSFC, LRO LOLA (relief, éclairage) ; UAI/USGS (noms de formations) ; NASA (régions Artemis III). Les calculs sont ceux de l'étude et sont à lire avec les limites indiquées dans la page.
